Built to be rebuilt.

  1. Self-hosted Kubernetes, no managed service.

    Every app I ship runs here. I built it on plain cloud servers, and I run it myself.

    Checked from outside every minute: 29,643 checks since 5 November, 7 failed.

  2. Fully GitOps: Git decides what runs.

    Nobody changes the cluster by hand. Every change is a pull request, and once it merges, Argo CD makes the cluster match Git. A rollback is a revert.

    16 of 16 apps match Git. 7 releases since 23 October.

  3. Every step is written down.

    Every decision has a dated record with its reason, and every step of the build is in a runbook. All of it is public.

    14 recorded decisions. Read how it is built

  4. Backups are tested, not trusted.

    A full backup leaves the cluster every day. On the 1st of each month, a drill restores it into a throwaway database and checks the data.

    4 min, passed, on 1 November. Next drill: 1 December.

  5. Rebuildable from scratch, with one command.

    kluster, the Go CLI I wrote, is where all of this leads. From an empty cloud project, one command builds the servers, installs every part from Git and restores the data.

    Rehearsed end to end in a separate project on 25 October.

Building reliable, scalable systems one node at a time.
